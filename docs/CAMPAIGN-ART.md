# Campaign art

- `src/art/braves.webp`: 10 portraits from the existing 31 July 2026 Sanada
  Ten Braves ImageGen set in the Obsidian vault. Sasuke uses his ninja-forward
  v02. Cropped and packed in campaign order (5 × 2, 224 px per frame). The
  source artwork is unchanged.
- `src/art/trophy-gold.webp`: OpenAI ImageGen, transparent master, resized
  for the game. Prompt: single antique-gold Japanese billiards trophy, six
  embossed coin recesses, crossed cue handles, crimson lacquer and a carved
  dark hardwood base, facing forward on transparent alpha, no text.
- `src/art/trophy-bronze.webp`: ImageGen edit of that master. Prompt: keep
  framing, silhouette, embossing, lacquer and base, and recolour the yellow
  gold metal to warm copper-brown bronze. Preserve transparent alpha.

The same cup artwork marks each named award. Bronze is a standard win; gold
is a win without a foul. Both grades retain the existing save format.
